# MelkaDLC 0.15-licensed

Новая сборка подключена к `https://melkadlc.onrender.com`. Токены Telegram, служебного API, PostgreSQL и ключи шифрования в APK/репозиторий не добавлялись.

## Реализовано

- Вход только после серверной активации ключа из `@MelkaDLCtrialbot` или проверки сохранённой сессии. Свободная ветка входа удалена, отсутствие конфигурации запрещает доступ.
- Исходный MainActivity не экспортирован; отрицательный результат gate немедленно завершает onCreate до создания оригинальных элементов управления.
- Серверный срок сопоставляется с монотонным временем, а не часами телефона. Проверка каждые 20 секунд; ошибка проверки закрывает доступ, допуск самостоятельно истекает максимум через 45 секунд. При перезапуске процесса допуск отсутствует до проверки сервера.
- Сессионный токен хранится через Android Keystore AES/GCM, UUID установки не содержит IMEI. Проверка проходит по HTTPS без переадресации bearer token.
- GitHub-ссылки и кнопка GitHub Release убраны из Android-интерфейса. Для обновлений и канала используется `@MelkaDLCRealese`.
- В закодированном блоке модуля заменены два фиксированных поля: `crack_komarq` → `MelkaDLC`, `tg:@crack_komarq` → `@MelkaDLCRealese`. Размеры/адреса полей сохранены. Ожидаемая CRC обновлена, сама проверка и её ветвления сохранены.
- В launch.sh изменён только ожидаемый SHA-256 модуля; хеши в проверке APK синхронизированы. Функции загрузки, файловый сервис и helper-библиотека сохранены.
- Новый versionCode 20, сертификат совпадает с опубликованной MelkaDLC 0.14. Новую сборку можно установить поверх этой версии. Для исходного skinchiki.apk с другим сертификатом сохраняется требование переустановки.

## Проверено

- ECJ-компиляция Java, сборка Android SDK D8, подписи v2/v3, zipalign, ZIP CRC.
- JVM-проверки активной/истёкшей/приостановленной/отозванной лицензии, границ короткого допуска, истечения по монотонному времени и отсутствия допуска при откате времени.
- Независимое сравнение DEX-инструкций загрузки/StorageServer, разрешённых замен pins, нативного модуля и сценария.
- У Render: `/health` = 200, отсутствие сессии = 401, неизвестный ключ = 404, неверный формат = 422. Проверки не расходовали Trial, не привязывали реальные ключи и не меняли финансовые данные production.
- Положительные сценарии лицензирования/привязки/сброса/блокировки проверяются существующим набором интеграционных тестов с отдельной PostgreSQL. Положительная активация реального ключа на физическом телефоне здесь не проверена.
- Публичная доставка восстанавливает уже подписанный APK без приватного ключа, сравнивает полный SHA-256 до публикации и скачивает результат после публикации.

## Оставшееся ограничение

**Кнопка `Zenin.cc` внутри закрытого UI модуля не удалена.** Она не представлена обычной строкой в доступном коде; безопасная точка удаления не установлена. Для её точного удаления без изменения функций модуля нужны исходники соответствующего окна. Смена двух найденных брендовых полей не выдаётся за удаление этой кнопки.

Root-сценарий с исходной игрой на ARM64-устройстве в этой среде не запускался. Изменения исполняемого кода модуля ограничены двумя immediate-значениями ожидаемой CRC брендового блока; прочие функции и ветвления не менялись. Публикация использует отдельный asset `MelkaDLC-licensed.apk`, сохраняя предыдущие файлы Release V1.1.0.
