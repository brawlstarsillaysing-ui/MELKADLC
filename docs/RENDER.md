# Настройка Render

Нужны три постоянно работающих компонента: API, один bot worker и PostgreSQL. Токен Telegram не предоставляет хостинг.

1. В своём аккаунте Render создайте Blueprint из существующего GitHub-репозитория MELKADLC. Файл конфигурации — `render.yaml`. Проверьте выбранную ветку и стоимость ресурсов перед созданием: этот документ не активирует оплату.
2. Для API задайте `KEY_ENCRYPTION_SECRET` (Fernet), `ADMIN_IDS`, реквизиты `PAYMENT_CARD` и **действительное имя получателя** `PAYMENT_RECIPIENT`. `SERVICE_TOKEN` и `KEY_HASH_SECRET` генерируются Blueprint. Секреты можно подготовить `python scripts/generate_secrets.py`; не помещайте вывод в Git.
3. Render предоставит настоящий HTTPS URL API. Проверьте, что `/health` возвращает `{"status":"ok"}`. Схема применяется через `alembic upgrade head` до запуска сервера.
4. Для worker задайте `BOT_TOKEN`, `BOT_USERNAME=MelkaDLCtrialbot`, `ADMIN_IDS` и `API_BASE_URL`, равный настоящему URL из шага 3 без завершающего `/`. Service token берётся из API через Blueprint; он должен совпадать у обоих сервисов.
5. Должен работать ровно один polling worker. Если у токена раньше был webhook, сначала явно переключите доставку после проверки текущего состояния; код не удаляет webhook автоматически и не сбрасывает сообщения.
6. Откройте бота, отправьте `/start`, выберите язык. Администратор отправляет `/admin`. Проверьте Trial, активацию, заявки и аудит. До настройки получателя новые пополнения намеренно недоступны.
7. Передайте реальный HTTPS URL в `android/build.py --api-url ...` и используйте сохранённый новый сертификат MelkaDLC. Установка этой сборки поверх ребрендинга с тем же новым сертификатом возможна при корректном versionCode; для следующей версии увеличьте его в build-скрипте. Нельзя автоматически заменять одноимённый Release Asset: это отдельный конфликт, требующий решения владельца.
8. Включите резервные копии PostgreSQL на выбранном плане и проверьте восстановление. Защитите доступ к Render и переменным окружения.

Без аккаунта Render и адреса реально созданного сервиса удалённое развёртывание и связь APK ↔ API ↔ бот не считаются выполненными. Лицензионная сборка 0.15 уже настроена на https://melkadlc.onrender.com.

Для временного ngrok-теста: запустите PostgreSQL и API локально, создайте HTTPS-туннель к порту API, укажите его настоящий origin при сборке APK, запустите bot worker с локальным `API_BASE_URL`. Закрытие туннеля/компьютера отключает API, поэтому такой вариант не подходит для постоянно работающего продукта.
