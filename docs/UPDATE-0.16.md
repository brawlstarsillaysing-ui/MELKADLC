# MelkaDLC 0.16-menu

Изменения относятся к оформлению нативного меню и загрузки. Backend и бот не меняются.

- RGBA-изображение кота 128×128 в закодированном блоке заменено на значок M из APK. Размер блока и размещение строк сохранены, оба брендовых поля содержат `MelkaDLC`.
- Два существующих callback отрисовки брендинга перенаправлены в отдельный ARM64-адаптер. На загрузочных вызовах он рисует M, плавно раскрывает «Melka DLC», затем сворачивает текст. Время загрузки, обработка ввода и переход к полному меню исходного модуля не задерживаются и не переписываются.
- В остальных местах сохраняется прежняя отрисовка со статичным значком M. Подписи, содержащие `zenin.cc`, `telegram`, `t.me/`, `@MelkaDLCRealese`, `@crack_komarq`, скрываются без изменения остальных текстов.
- **Фильтр скрывает подписи ссылок. Удаление фона, кликабельной области и обработчиков этих кнопок не подтверждено.** Эти элементы находятся внутри закрытого UI. Не заявляется полное удаление кнопок или отключение всех способов перехода по ссылке.
- Модуль сохраняет размер, экспорты, релокации и весь исполняемый код функций за пределами двух callback брендинга и двух значений ожидаемой CRC. Дополнительный UI-код размещён в проверенной пустой области RX, состояние — в расширенном нулевом хвосте RW, без перемещения существующих сегментов. Разрешённые диапазоны изменений явно проверяются в `android/native_branding.py`.
- Хеш модуля и связанные pins обновлены. Проверки целостности, helper-библиотека, файловый сервис и логика загрузки сохранены.
- Лицензирование и API сохранены из 0.15. Отдельное сравнение DEX проверяет `LicenseLease` и `GateActivity`, разрешая только замену отображаемой версии.
- VersionCode 21, versionName `0.16-menu`, прежний сертификат MelkaDLC. После обновления полностью закройте игру и запустите заново: уже загруженная старая библиотека сама не заменится.

## Проверка

`android/native-ui/test_ui.py` исполняет упакованный ARM64-код в Unicorn с подставными API отрисовки: обе сигнатуры callback, перемещение базы ASLR, сохранность регистров/стека, восстановление указателя позиции, раскрытие/сворачивание, статичный заголовок и ограниченный диапазоном текста фильтр ссылок. Старые функции OpenGL здесь заменены заглушками; это не проверка на Android.

Сборка дополнительно проверяется Android SDK apksigner/zipalign, сравнением DEX и полных разрешённых диапазонов модуля, точным восстановлением подписанного APK и итоговым SHA-256. Существующие серверные и JVM-тесты запускаются в CI.

Физический Android/root-запуск и внешний вид в игре в этой среде не проверены. Артефакт публикуется отдельно как `MelkaDLC-menu.apk`, прежние assets и тег V1.1.0 сохраняются.
