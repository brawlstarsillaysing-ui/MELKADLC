# Результаты проверки — 17.11.2026

## Сервер, PostgreSQL и бот

**22 теста прошли**, Python 3.12.14, настоящий PostgreSQL 17 в отдельной БД `melka_test`. Используются транзакции, параллельные отдельные соединения и настоящий HTTP-контракт FastAPI. Aiogram-обработчики запускаются с локальным перехватом Telegram-отправок.

Тот же набор успешно выполнен в GitHub Actions для коммита `82e1e7132b0ec4529abf45877e7a88292b628e9b`: https://github.com/brawlstarsillaysing-ui/MELKADLC/actions/runs/44035074866.

Проверены:

- Регистрация, сохранение языка/лимитов при повторном входе и смене username.
- Двадцать одновременных запросов Trial возвращают один ключ.
- Пять последовательных Trial по 86400 секунд с первой активации; шестой отклоняется.
- Одновременная активация на восьми разных установках допускает одно устройство.
- Повторный сброс идемпотентен, два самостоятельных сброса по умолчанию, срок сохраняется, старая сессия инвалидируется.
- Подтверждение одного платежа шестнадцатью запросами начисляет деньги один раз; отклонение не начисляет деньги.
- Одна покупка при повторных запросах списывается один раз. Разные одновременные покупки не создают отрицательный баланс.
- Реферальные 30% только с cash-части; bonus-only покупка не генерирует награду; возврат сторнирует потраченную награду и создаёт долг вместо инфляции.
- Промокоды на баланс, лицензию, продление и скидку; ограничения пользователя, общий лимит, одновременная активация, повторная обработка, одноразовая скидка.
- Административные изменения идемпотентны, записываются в аудит; бонусные начисления не считаются внешней выручкой.
- Изменившаяся цена отклоняет старое подтверждение без списания; блокировка аккаунта и приостановка ключа прекращают выдачу доступа.
- Состояние сохраняется после закрытия/повторного открытия соединений с PostgreSQL.
- Авторизация служебных/административных запросов, запрет лишних входных полей, ограничение частоты запросов.
- Реальные обработчики `/start`, выбора украинского языка, Trial и меню; поддельный callback админки не даёт прав.
- Обращение с файлом, сохранение ответа, рассылка только после создания черновика и подтверждения.

`ruff check` прошёл. `alembic check`: **No new upgrade operations detected**. Миграция применена, SQL-схема экспортирована в `database/schema.sql`. В тестовом раннере есть одно deprecation-предупреждение Starlette о будущем переходе TestClient на httpx2; на результат тестов оно не влияет.

Docker-образ собран; non-root API запущен в отдельном контейнере с PostgreSQL, `/health` вернул **200 {"status":"ok"}**. Для локального Cloud proxy сертификат CA передавался BuildKit secret через временный Dockerfile; сертификат и секреты не добавлялись в публикуемый образ/репозиторий. Обычный Dockerfile предназначен для стандартного TLS окружения Render/VPS.

Реальный токен Telegram проверен через `getMe`: username **MelkaDLCtrialbot**. Production polling и удалённый Render-сервис не запущены. Ручное банковское поступление и реальные покупки не выполнялись.
