# Изменения и сохранённые компоненты

## Android

Изменены название приложения/заголовки/тема/иконка; добавлены splash с проверкой реальных компонентов, новая точка входа, кнопки Telegram/обновлений/отчёта и исходники лицензионного экрана. Проверка лицензии активируется параметром сборки с реальным HTTPS origin. В текущей сборке она явно отключена до развёртывания сервера.

Сохранены: исходный package ID, MainActivity, классы загрузки и диагностики, кнопки исходного запуска и журнала, файловый сервис, скрипт запуска, обе ARM64-библиотеки, SDK-ограничения, проверка содержимого и сертификата. Проверено статически; реальная работа на устройстве не подтверждалась. Подпись новая с разрешения владельца, нужна переустановка. Старый APK в Release не меняется.

Внутренние имена файлов `launcher_cat`, `libmodule.so`, `liblauncher.so`, package/class ID намеренно сохраняются там, где на них опирается оригинальный код. `launcher_cat` теперь отображает M. Брендинг внутри неизменённых `.so` не редактируется.

## Новые компоненты

- `backend/`: транзакционные сервисы, защищённый API, хеширование/шифрование ключей, серверное время, сессии/привязки, лимиты, trial, продажи, UAH-кошельки/ledger, ручные платежи/чеки, рефералы/сторно, промокоды, поддержка, аудит и операции администратора.
- `telegram_bot/`: aiogram 3, RU/UK/EN пользовательские интерфейсы, Inline-навигация, подтверждение покупок/сбросов, чеки, профиль/истории, поддержка, администрирование с JSON-формой/предпросмотром и рассылки.
- `database/`: PostgreSQL, Alembic, экспорт SQL-схемы.
- Docker, Caddy HTTPS, Blueprint Render, `.env.example`, скрипт подготовки секретов и backup.
- `tests/`: 22 автоматизированных теста; GitHub Actions workflow для их запуска.
- `docs/`: запуск, Render, Android/API, администраторы, реквизиты/цены, тестирование и ограничения.

## Что требует завершения с участием владельца окружения

Создание Render/VPS и реального API URL, настройка имени получателя платежа, запуск одного polling worker и постоянной PostgreSQL, сборка с API, устройство для Android/root-проверки. Отдельная веб-админка не создавалась; административная работа доступна в боте/API. Внешние банковские операции и необратимые реальные платежи не выполнялись.
